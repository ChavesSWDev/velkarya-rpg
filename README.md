## About

Velkarya is an original dark fantasy setting — a continent of broken seals, demanding gods and a Veil that is starting to tear — built to be played with friends as an online tabletop RPG.

The website is the gateway to that world: an immersive, scroll-driven experience with an interactive map, regions, factions and the chronicle of the continent.

> This is a showcase repository. The source code is private; this page documents the project.

## Highlights

- 🎲 **Real-time table on Firestore** — the whole party sees every dice roll at once.
- 🧊 **3D dice with Three.js** — physical-feeling rolls right in the browser.
- 🗺️ **Cinematic world map** — scroll-driven storytelling across the continent with GSAP.
- 🧙 **Accounts, player dashboard and campaigns** — plus a rules system with 11 playable races.

## Tech stack

`React` · `Three.js` · `Firebase (Auth, Firestore)` · `Zustand` · `GSAP` · `Framer Motion` · `Vite` · `Vercel`
